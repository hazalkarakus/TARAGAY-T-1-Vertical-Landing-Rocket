# TARAGAY-T1 — Vertical Landing Rocket

As the project's name suggests, TARAGAY-T1 is a short-hop, controlled vertical-landing demonstrator, not a full-altitude sounding rocket. Its flight computer lifts the vehicle a few meters above its separation point, holds it steady through a brief powered hover, and then brings it down for a soft touchdown.

Hover is not the end goal — it's the vehicle's most demanding proving ground, where altitude hold and attitude stabilization are tested under real flight conditions. But the mission itself, from ascent through capture and hover to descent, is built end-to-end for one purpose: a controlled vertical landing.
